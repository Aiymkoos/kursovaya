# ҚОСЫМША Ә. ҚОЛДАНУШЫ БАСҚАРУЫ

## 1 Жүйені іске қосу тәртібі

Ойынды екі тәсілмен іске қосуға болады.

Бірінші тәсіл — дайын орындалатын файл. Windows жүйесінде Kolenke.exe файлын екі рет шертіп іске қосыңыз. Python орнату қажет емес. Егер Windows қорғаныс терезесі («Windows компьютеріңізді қорғады») шықса, «Қосымша мәлімет» және «Бәрібір іске қосу» батырмаларын басыңыз: файл әзірленген бағдарламаның өзі.

Екінші тәсіл — бастапқы кодтан іске қосу. Python 3.10 және одан жоғары нұсқасы орнатылған болуы керек. Бағдарлама қалтасын ашып, командалық жолда мына пәрмендерді орындаңыз:

- pip install -r requirements.txt — PyGame кітапханасын орнату;
- python main.py — ойынды толық экранда іске қосу;
- python main.py --windowed — ойынды терезеде іске қосу;
- python main.py --selftest — терезесіз өздігінен тексеру (ресурстар, сахналар, кадрлар);
- python -m pytest -q — автоматты тесттерді іске қосу.

## 2 Басқару интерфейсі

Ойын іске қосылғанда басты мәзір ашылады (Ә.1-сурет). Таңдау ↑ және ↓ пернелерімен жасалады, растау — Enter. Бұрын сақтау жасалған болса, «Жалғастыру» пункті пайда болады. Жоғарғы жағында ойын атауы, екі жақта басты кейіпкер мен көлеңке жұтқан достың портреті орналасқан, артта боран жауып тұр.

[image: img/01_menu.png | w=14 | Басты мәзір]

Жатақханада жүру (Ә.2-сурет). Басты кейіпкер A/D (немесе ← →) пернелерімен қозғалады. Сол жақ жоғарыда түн индикаторы (үш шеңбер: қазіргі түн қызыл), оң жақ жоғарыда естеліктер журналындағы жазба саны (Tab), ортасында локация атауы көрсетіледі. Есікке немесе кейіпкерге жақындағанда жоғарыда «E» белгісі бар қалқымалы хабарлама шығады: E басылса, есік ашылады, диалог немесе шайқас басталады. Қараңғы бөлмелерде жарықтың көзі: шам, терезе, есіктің астындағы жарық және басты кейіпкердің фонарьі.

[image: img/02_corridor.png | w=14 | Жатақхана дәлізі]

[image: img/03_room.png | w=14 | Дарханның бөлмесі: кейіпкермен сөйлесу ұсынысы]

Диалог (Ә.4–Ә.6-суреттер). Төменде диалог терезесі орналасады: үстінде сөйлеушінің аты (оның акцент түсімен), ішінде мәтін. Мәтін әріптеп теріледі; Space пернесі қалғанын бірден көрсетеді, ал мәтін толық шыққан соң келесі репликаға өтеді. Таңдау болса, нұсқалар нөмірмен көрсетіледі (1–4). Жаңа жазба журналға түскенде жоғарыда «Жаңа жазба журналда» хабарламасы шығады. Көлеңке жұта бастағанда кейіпкер портреті солғындап, шеттері бұзылады, ал бет белгілері өшеді.

[image: img/04_dialogue_choices.png | w=14 | Диалогтағы таңдау нұсқалары]

[image: img/05_dialogue_fading.png | w=14 | Кейіпкердің портреті көлеңке жұта бастағанда]

[image: img/06_dialogue_shadow.png | w=14 | Кейіпкер көлеңкеге толық айналды]

Естеліктер журналы (Ә.7-сурет) Tab пернесімен ашылады. Онда диалогта байқалған бөлшектер кейіпкерлер бойынша топтастырылған. Дәл осы бөлшектер шайқаста қарсыластың дайындық қимылын көрсетеді.

[image: img/07_journal.png | w=14 | Естеліктер журналы]

Екінші түнде бір бөлмеде екі кейіпкер бірден көрсетіледі; сөйлесіп жатқанының портреті ашық, екіншісі күңгірт.

[image: img/08_night2_cast.png | w=14 | Екінші түн: екі кейіпкер бір бөлмеде]

Жекпе-жек (Ә.9–Ә.11-суреттер). Жоғарғы сол жақта ойыншының денсаулық жолағы (көк), одан төменде естелік жолағы (үш бөлікке бөлінген) және естелік слоттары (1 «Жылу», 2 «Зейін», 3 «Қайтару»); оң жақта қарсыластың денсаулық жолағы. Қарсылас соққыға дайындалғанда оның басының үстінде белгі шығады: сөйлесуде сол детальді байқасаңыз ғана көрінеді. Шеңбер кішірейіп, ақ түске боялғанда L пернесін басыңыз: парирлеу іске асады — «Парирлеу!» жазуы шығады, уақыт баяулайды, камера жақындайды, қарсылас тепе-теңдігін жоғалтады. Қарсыластың денсаулығы 35%-тен төмен түскенде (немесе ол парирленгенде) және естелік жеткілікті болса, экранда «3 — естелік арқылы адамды қайтару» хабарламасы пайда болады.

[image: img/09_fight_tell.png | w=14 | Шайқас: қарсыластың дайындық қимылының белгісі]

[image: img/10_fight_parry.png | w=14 | Сәтті парирлеу]

[image: img/11_fight_restore_hint.png | w=14 | Адамды қайтару мүмкіндігі]

Түн қорытындысы және финал (Ә.12–Ә.14-суреттер). Түннің барлық шайқасы біткен соң қорытынды экран шығады: әр досының портреті (қайтқаны — адам кейпінде, қалғаны — көлеңке), оның күйі және естелік қоры. Space пернесі келесі түнге өткізеді және ойынды автоматты түрде сақтайды. Үшінші түнде басты кейіпкердің өзі айнала бастайды: экран қараяды, интерфейс элементтері біртіндеп жоғалады, мәтіннің кейбір әріптері өшеді. Үшінші түннен кейін құтқарылғандар санына байланысты финал көрсетіледі.

## 3 Жұмыс режимдерін таңдау және қауіпсіздік шаралары

- Толық экран және терезе режимі F11 пернесімен ауыстырылады; ойын терезеде де іске қосыла алады (--windowed).
- Дыбысты M пернесімен өшіруге және қосуға болады. Дыбыс құрылғысы жоқ болса, ойын үнсіз жұмыс істей береді.
- ESC пернесі мәзірге немесе алдыңғы экранға қайтарады; шайқастан шыққанда нәтиже сақталмайды.
- Автосақтау әр түн аяқталғанда жасалады. Файл Windows жүйесінде %APPDATA%\Kolenke\save.json жолында сақталады. Файлды қолмен өзгертпеңіз; ойынды қайта бастау үшін мәзірден «Жаңа ойын» таңдаңыз. Финалдан кейін сақтау жойылады.
- Ойында қысқа жарық жарқылдары мен экран дірілі бар. Жарыққа сезімтал адамдар ойнамас бұрын осы жайтты ескергені жөн.
