# План графики на завтра (спрайты, анимация боя, боковые фоны)

Проблемы сейчас:
1. Фоны сгенерированы «с перспективой» (взгляд вглубь), а ходьба идёт «вид сбоку»: герой стоит не на полу.
2. В бою спрайты статичны: нет поз удара, реакции на урон, блока, падения.
3. Спрайтов нет у Мадины и Бекзата (в ходьбе и бою они рисуются кодом).

## A. Боковые фоны для ходьбы (4 шт, ~32 токена)
Запрос (к STYLE из PROMPTS.md): `2D side-scrolling game background, flat side view, long straight wall with a flat floor line at the bottom third, no perspective, ..., STYLE`
- `corridor.png`: длинный коридор, вид сбоку: окна, лампы, двери вдоль стены (широкий кадр, лучше 21:9 или два соседних 16:9, чтобы шов совпал).
- `room_darkhan.png`, `room_girls.png`, `room_bekzat.png`: комнаты в виде «сцены» (как разрез): пол по линии ~640 px, мебель на фоне стены, БЕЗ людей.
Код: `render/artscene.py` уже умеет рисовать фон и сдвигать его; нужно подогнать линию пола (GROUND) под картинку.

## B. Листы поз (sprite sheet) на каждого героя (5 героев × 1–2 генерации)
Чтобы поза и одежда совпадали, просить **одну картинку с сеткой поз**, а не отдельные кадры:
`character sprite sheet, same character in a 3x3 grid of poses on plain white background: idle, walking, light punch, heavy punch, blocking, hit reaction (recoiling), stagger, knocked down, victory, [HERO], side view facing right, STYLE`
Затем код режет лист по сетке (`tools/slice_sheet.py`), вырезает фон (rembg) и кладёт в `assets/sprites/<имя>/<поза>.png`.
Нужные позы: idle, walk (2 кадра), light, heavy, block, hurt, stagger, dead.
Если сетка выходит кривой, запасной путь: image-to-image с референсом в Leonardo (Consistent Character) — дороже по токенам.

## C. Код (после картинок)
- `fighter_draw.draw_fighter_sprite`: выбор картинки по `f.state` и кадру (startup/active/recovery) вместо наклона одной картинки.
- Вспышка и сдвиг при уроне, падение (dead) из реального кадра.
- Ходьба: чередование двух кадров walk.
- Герой (me) + 4 врага: darkhan, zhanel, madina, bekzat.

## Бюджет токенов Leonardo
Free: 150/день, ~8 токенов за картинку (Lucid Origin, 1 картинка). ВАЖНО: перед запуском выставить в левой панели «Number of generations = 1» (по умолчанию ставит 4 и тратит 32) и модель Lucid Origin (не Auto).
Оценка: фоны 32 + листы поз 5×8 = 40 (+ запас на перегенерацию 40) ≈ 110 токенов: влезает в один день.

## Порядок работы
1. Фоны сбоку (A) → подогнать линию пола, проверить ходьбу.
2. Лист поз героя → нарезка → проверить бой с Дарханом.
3. Остальные листы поз → нарезка.
4. Сборка .exe, проверка.

Известное: веб-версия (GitHub Pages) не стартует (серый экран), причина не найдена; играть через `.exe` из релиза `latest`.
