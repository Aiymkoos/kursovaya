# План: «Көлеңке» (Тень)

Визуальная новелла + движение + файтинг, 2D, Python + PyGame, 60 FPS.

## Архитектура

```
kolenke/
  main.py                 # точка входа, главный цикл 60 FPS
  core/
    game.py               # Game: стек сцен, фиксированный шаг, события
    scene.py              # базовый класс Scene (menu, explore, dialogue, fight, ending)
    input.py              # маппинг клавиш, буфер ввода (N кадров)
    assets.py             # загрузка/кэш спрайтов и звуков
    save.py               # сохранение/загрузка JSON
  story/
    graph.py              # DialogueGraph: узлы, выборы, переходы
    flags.py              # Flags: запись выборов, чтение условий
    journal.py            # журнал воспоминаний (Tab)
    data/                 # JSON-сценарии: night1.json, night2.json, night3.json
  explore/
    player.py             # движение A/D/←→, взаимодействие E
    locations.py          # локации общежития (комнаты, коридор)
  combat/
    fsm.py                # кадровый FSM бойца: idle, light, heavy, block, parry, hit, stagger
    hitbox.py             # hitbox/hurtbox, фреймданные
    fighter.py            # Fighter: HP, шкала воспоминаний, состояние
    parry.py              # окно парирования с кадровой точностью, slow-mo
    memory.py             # использование воспоминаний 1–3, цена на следующую ночь
    ai/
      markov.py           # таблица частот, предсказание следующего действия
      adaptive.py         # выбор контрдействия по предсказанию
      metrics.py          # точность предсказания -> CSV для эксперимента
    tells.py              # «подготовительные движения»: показ только если деталь найдена в диалоге
  render/
    silhouette.py         # силуэт + один акцентный цвет, потеря деталей по мере «поглощения»
    particles.py          # система частиц тени
    ui.py                 # журнал, индикатор ночи, полоски HP/памяти, маркер tell
    effects.py            # slow-mo, затемнение экрана (финал, ночь 3)
  audio/
    sfx.py, music.py      # метель, удары, парирование, лейтмотивы героев
tests/                    # pytest: граф диалога, флаги, FSM, марков, окно парирования
tools/
  experiment.py           # прогон бота против ИИ, замер точности предсказания
  build_exe.bat/.spec     # PyInstaller
docs/
  PLAN.md
```

## Ключевые механики

- **Цикл ночи:** разговор -> превращение -> бой (3 фазы на ночь, 3 ночи).
- **Разговор:** граф узлов JSON; Space — следующая реплика, 1–4 — выбор. Выбор пишет флаги; флаги открывают «детали» героя (tell).
- **Бой:** J лёгкий, K тяжёлый, L блок, L в точное окно = парирование (slow-mo + частицы). Кадровые данные (startup/active/recovery) в JSON. Буфер ввода ~6 кадров.
- **Tell:** подготовительное движение врага подсвечивается на экране только если игрок узнал соответствующую деталь в диалоге. Ночь 2: tell виден только у выбранного героя, второй — «слепой» бой.
- **Воспоминания (1–3):** вернуть человеческий облик вместо убийства; тратят память игрока и уменьшают запас на следующую ночь.
- **Адаптивный ИИ:** цепь Маркова порядка 1–2 по действиям игрока, таблица частот, выбор контрдействия; метрика точности (доля верных предсказаний) логируется.
- **Финалы:** 4 концовки, зависят от числа спасённых из четырёх (границы диапазонов уточнить при написании сценария).
- **Ночь 3:** затемнение экрана и исчезновение элементов интерфейса, герой сам начинает превращаться.

## Решения

- Графика: сначала процедурные силуэты (примитивы/программные), позже можно заменить на PNG — интерфейс `assets.py` это допускает.
- Звук: сначала заглушки/синтез через `pygame.mixer`, потом реальные файлы.
- Тесты: логика (граф, флаги, FSM, ИИ) без окна, через `SDL_VIDEODRIVER=dummy`.
- Язык интерфейса и текстов: казахский (основной) + русский как запасной; строки в JSON, не в коде.

## Визуальный стиль и «сок» (цель: вид дорогой игры, только кодом)

- Освещение: тёмный слой + световые пятна (multiply), мерцающие лампы, фонарь игрока, свет из окон и из-под дверей.
- Силуэты: чёрное тело + один акцентный цвет, акцент «светится» поверх темноты и тускнеет по мере поглощения.
- Атмосфера: вьюга за окнами (частицы), виньетка, параллакс (колонны переднего плана), плавная камера, пыль из-под ног, затемнение при смене локации.
- Бой (этапы 3–4): hitstop, тряска экрана (`ScreenShake`), замедление при парировании, вспышки и след от удара, частицы тени, анимация замаха (anticipation).
- Бюджет: кадр ≤ 16,7 мс; статичные декорации рисуются один раз в Surface; измерение в `tests/test_explore.py::test_frame_time_budget` (сейчас ≈ 9 мс в сцене исследования).

## Принятые решения (пользователь)

- Язык игры и отчёта: казахский. Строки в `kolenke/data/strings_kk.json`; шрифт DejaVu Sans (есть ә, ғ, қ, ң, ө, ұ, ү, һ, і), лежит в `assets/fonts/`.
- Графика: только код (процедурные силуэты), PNG не нужны.
- Экран: полный экран по умолчанию (F11 переключает окно/полный экран). Внутреннее разрешение 1280×720, масштабируется под экран (`pygame.SCALED`).
