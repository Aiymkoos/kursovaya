# ҚОРЫТЫНДЫ

Курстық жоба барысында Python тілінде PyGame кітапханасын пайдаланып, «Көлеңке» — визуалды новелла, қозғалыс және жекпе-жек біріктірілген 2D ойыны әзірленді. Бастапқы тапсырмада қойылған міндеттер орындалды.

Жоба барысында шешілген негізгі міндеттер:

- сценарий түйіндер мен таңдау бұтақтарынан тұратын бағытталған граф түрінде JSON файлдарында сипатталды; граф жүктелген кезде тексеріледі (өтулер, қол жетпейтін түйіндер, естеліктер, портрет күйлері);
- флагтар жүйесі мен естеліктер журналы жасалды, ал флагтар жекпе-жек параметрлеріне әсер етеді: дайындық белгісінің көрінуі, қарсыластың күші, естелік қорының бастапқы мәні;
- жекпе-жек кадрлық ақырлы автомат, hitbox/hurtbox, 8 кадрлық парирлеу терезесі және 6 кадрлық енгізу буфері негізінде іске асты; hitstop, экран дірілі, парирлеудегі баяулау және зум сияқты эффектілер логикадан бөлек жасалды;
- ойыншының әдеттерін Марков тізбегі арқылы үйренетін бейімделгіш қарсылас жасалып, болжау дәлдігі өлшенді: қатаң әдетті ойыншыда екінші ретті модель {{acc:pattern:markov2}} дәлдікке жетті, ал кездейсоқ ойында ≈ 1/3 болды;
- силуэттік портреттер, жарықтандыру, бөлшектер, боран, виньетка және дыбыс (кейіпкер мотивтерімен) сыртқы суретсіз және аудио файлсыз бағдарламалық түрде жасалды;
- үш түн, төрт финал, JSON сақтау және үшінші түндегі бүліну (экранның қараюы, интерфейстің жоғалуы) іске асырылды;
- бағдарлама {{tests}} автоматты тестпен қамтылды, PyInstaller арқылы жинау конфигурациясы және терезесіз өздігінен тексеру режимі (--selftest) жасалды.

Жобаның тиімділігі мен сенімділігі. Бағдарламаның бастапқы коды шамамен {{loc}} жол. Сахналардағы бір кадрды есептеу және сызу уақыты әзірлеу компьютерінде шамамен {{frame_ms}} мс болды, ал 60 кадр/с үшін шек — 16,7 мс; яғни Core i3 деңгейіндегі компьютерге қойылатын талап үшін шамамен екі еселік қор қалдырылды. Ауыр бөліктер (фондар, портреттер, дыбыстар) бір рет жасалып кэштеледі. Бүлінген сақтау файлы, аудио құрылғының жоқтығы сияқты қате жағдайлары өңделеді және ойынды тоқтатпайды. Шектеу: өнімділік талабы нақты Core i3 құрылғысында тікелей тексерілмеді, ол қордың арқасында орындалады деп бағаланады; Windows үшін .exe файлы build_exe.bat арқылы Windows ортасында жиналады.

Практикалық маңызы. Әзірленген бағдарлама толық ойын ретінде көрсетіле алады. Диалог графы, флагтар жүйесі, кадрлық жекпе-жек ядросы және бейімделгіш ИИ бөлек модульдер ретінде жазылғандықтан, оларды ұқсас жобаларда қайта қолдануға болады, ал эксперимент нәтижелері ойынға арналған Марков негізіндегі қарсыласты бағалауға мысал бола алады.

Мүмкін жетілдіру жолдары: бастапқы кодты өзгертпей-ақ графикада қолмен салынған суреттерді қолдану (портреттер мен фондар интерфейс арқылы ауыстырылады); бейімделгіш ИИ-ге қарсыластың күйін және арақашықтықты контекст ретінде қосу; гейпадті қолдау; ойынның басқа тілдерге аударылуы (интерфейс жолдары бөлек JSON файлында); көбірек түндер мен кейіпкерлерді қосу; ИИ-ді нағыз ойыншылармен сынау.
