# kursovaya

Курсовая работа: «Көлеңке» — 2D-игра (визуальная новелла + движение + файтинг). Полный план: `docs/PLAN.md`.

## Стек
Python 3 + PyGame. Диалоги и сейвы — JSON. Тесты — pytest. Сборка .exe — PyInstaller.

## Как запускать
`pip install -r requirements.txt && python main.py` (F11 — окно/полный экран, ESC — выход из меню). Тесты: `python -m pytest -q`.

Код: пакет `kolenke/` (`core/` — цикл, сцены, ввод, ресурсы; `story/` — граф диалога, флаги, журнал; `explore/` — игрок, локации; `render/` — освещение, частицы, силуэты, портреты, эффекты; `scenes/`; `data/` — JSON: строки и `night1.json`), `assets/fonts/`, `tests/`.

## Формат диалога (`kolenke/data/night*.json`)
Узлы: `speaker`, `text`, и ровно одно из `next` / `choices` / `end`; опционально `set` (флаги) и `memory` (запись в журнал). Выбор: `text`, `next`, `set`, `memory`, `requires`. Граф проверяется при загрузке (битые ссылки, недостижимые узлы, неизвестные записи журнала).

## Визуальный стиль
Портреты (`render/portrait.py`) берутся из `assets/portraits/<имя>_<состояние>.png`, если файл есть, иначе рисуются кодом; 3 состояния: human → fading → shadow. Фоны — `assets/bg/`, полноростовые спрайты для сцены ходьбы — `assets/sprites/<имя>.png` (`render/sprite.py`; нет файла — код рисует силуэт). Бой рисуется кодом (`render/silhouette.py`). Узлы диалога могут менять состояние через `states`; фон диалога — `bg` (комната). 3-я ночь: `game.corruption` затемняет экран и скрывает интерфейс.

## Производительность
Минимальное железо из методички (ТЗ п. 4.3): Windows 10+, Core i3, 4 ГБ. Держать кадр ≤ 16,7 мс; тяжёлое рисовать один раз заранее.

## Отчёт
`docs/report/` — отчёт на казахском (.docx/.pdf); сборка `python tools/build_report.py`; тексты в `docs/report/text/*.md`, таблицы в `docs/report/*.csv` (тесты сверяют их с кодом). Желтые поля — заполнить вручную.

## Решения
- Язык игры и отчёта — казахский (строки в JSON, не в коде). Графика: картинки сгенерированы в Leonardo.ai (Lucid Origin), фон у портретов и спрайтов вырезан `rembg`; промпты в `docs/PROMPTS.md`; без файла игра рисует кодом (указывать в записке!). Предыстория — пролог `night0.json`. Полный экран, логика 1280×720.
