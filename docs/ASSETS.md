# Картинки для игры «Көлеңке»

Стиль: тёмная визуальная новелла. Палитра тёмно-синяя и угольная, мягкий объёмный свет, вьюга за окнами. Персонажи — чёрные силуэты плюс один акцентный цвет. По мере того как Тень «съедает» человека, детали исчезают.

Бой рисуется кодом (силуэты). Картинки нужны только для диалогов и меню.
Если файла нет, игра рисует замену кодом. Добавлять картинки можно по одной, код менять не нужно.

## Как делать

1. Сначала сделайте одну картинку и подгоните стиль. Потом генерируйте остальные с **тем же** стилевым куском запроса, чтобы всё было в одном стиле.
2. Фоны: PNG, **1920×1080** (16:9), без текста и без людей.
3. Портреты: PNG, **высота около 1400 px**, **прозрачный фон**. Если нейросеть даёт фон, уберите его в remove.bg или rembg.
4. Кладите файлы точно с этими именами в `assets/`.

**Общий стиль для запросов (добавлять в каждый):**
`dark moody visual novel illustration, deep navy and charcoal palette, soft volumetric lighting, painterly, cinematic, snowstorm night, no text, no watermark`

## Портреты (12 обязательных), папка `assets/portraits/`

Для каждого друга три файла: `<имя>_human.png`, `<имя>_fading.png`, `<имя>_shadow.png`. Имена: `darkhan`, `zhanel`, `madina`, `bekzat`.

- **`_human`**: человек до превращения. Видны лицо и одежда, есть один акцентный цвет (шарф или деталь одежды). Полупрофиль, по пояс.
- **`_fading`**: тот же человек. Детали исчезают: лицо стёрто, контуры растворяются в тёмном дыму. Акцентный цвет тускнеет.
- **`_shadow`**: чистый чёрный силуэт той же позы. Остаётся только акцентный цвет (глаз или шарф).

Чтобы позы совпадали, в запросе используйте один и тот же текст, меняя только состояние.

**Шаблон запроса (подставьте имя, описание и акцентный цвет):**
`half-body character portrait, [описание героя], three-quarter view, [акцентный цвет] scarf as the only color accent, [STATE], plain transparent background, visual novel sprite, [общий стиль]`

где `[STATE]`:
- human: `clearly visible face and details`
- fading: `details dissolving into dark smoke, face erased, edges disintegrating, accent color dimming`
- shadow: `pure black silhouette, no face details, only the accent color remains`

**Мотивы героев** (по ТЗ):
- Дархан: наубайхана (пекарня), пышақ (нож). Акцент: оранжевый.
- Барабаншы (барабанщик/-ца): барабан, ритмичные фразы.
- Тігінші (швея/портной): швейная машинка, мелкие точные движения.
- Бекзат: метроном (финал, он сам начинает превращаться).
